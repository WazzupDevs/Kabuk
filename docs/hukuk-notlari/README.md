# Hukuk notları

Araştırma notları; hukuki görüş değildir.

- `kvkk-dm-surumleri.md`: DM düzenleme sürümlerinin saklanmasının KVKK açısından değerlendirmesi.
- `veri-akislari.md`: kişisel veri akışları ve yurt dışı aktarımlar (koddan çıkarım).

Yasal metinlerin kaynağı `docs/legal/`'dir; bu klasör yayınlanmaz (`scripts/build-site.ts` yalnız `docs/legal/`'i okur).
