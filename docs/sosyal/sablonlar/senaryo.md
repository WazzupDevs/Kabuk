```

Kanal: TikTok + IG Reels | Uzunluk: __ sn | Yayın: __:__
Hedef: (kaydetme / paylaşım / yorum / link tıklaması / testçi)
Görsel: gorsel/icerik.json → [id] (kapak ya da animasyon)
```
