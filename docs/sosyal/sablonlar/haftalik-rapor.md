# Haftalık rapor şablonu

Her pazartesi bir önceki haftanın raporu `raporlar/YYYY-AA-GG.md` olarak yazılır (tarih haftanın pazartesisi). Rakamlar yayından 48 saat sonra okunur.

```
# Hafta [N] · [başlangıç]–[bitiş]

## Özet (3 satır)
- En iyi içerik: … (neden)
- En zayıf içerik: … (neden)
- Gelecek hafta değişecek tek şey: …

## Hedefe göre
| Ölçüt | Hafta | Toplam (30 gün) | Hedef | Durum |
| --- | --- | --- | --- | --- |
| Kapalı test katılımcısı | | | 30 | |
| Bio linki tıklaması | | | 400 | |
| TikTok takipçi | | | 1.000 | |
| IG takipçi | | | 500 | |
| Çekim izni alınan mekan | | | 3 | |

## İçerik tablosu
| Gün | İçerik | Kanal | İzlenme | 3 sn tutma | Tamamlanma | Beğeni | Yorum | Kaydet | Paylaş | Profil ziyareti | Takip |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| Pzt | | TikTok | | | | | | | | | |
| Pzt | | Reels | | | | | | | | | |

Hesap: etkileşim oranı = (kaydet + paylaş) / erişim. Kanca gücü = 3 sn tutma. İçerik gücü = tamamlanma.

## Ayaklara göre
| Ayak | İçerik sayısı | Ort. izlenme | Ort. kaydet+paylaş % | Karar (artır / koru / azalt) |
| --- | --- | --- | --- | --- |
| Masada ne oynanır | | | | |
| Kanki evreni | | | | |
| Mekandan anlar | | | | |
| Masa sorusu | | | | |
| Nasıl çalışır ve güven | | | | |

## Saat denemesi
| Saat | Ort. ilk 1 saat izlenme |
| --- | --- |

## Yorumlardan
- Sık sorulan: … (cevap videosuna aday)
- Şikayet / yanlış anlama: … (ürün ekibine iletilecek mi?)

## Gelecek hafta
- Takvim değişikliği: …
- Yeni deneme: …
```
