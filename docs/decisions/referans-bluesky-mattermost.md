# Bluesky social-app ve Mattermost Mobile teknik referans (6 Kasım 2026)

Proje sahibinin kararı: Telegram Android'in yanına iki React Native referansı eklendi.

- Gerekçe: Telegram native Android'dir; aynı işin Expo ve React Native'de kurulduğu olgun örnekler gerekir. Bluesky social-app (MIT) yığınımıza en yakın repo (Expo, Reanimated, expo-image, react-native-keyboard-controller); Mattermost Mobile (Apache-2.0) yıllardır kullanılan React Native sohbet uygulaması.
- Sıra: davranış ve teknik önce Telegram'dan, yığına uyarlama bunlardan.
- Lisans: ikisi de izin verici; kısa parça uyarlanırsa dosyaya kaynak ve telif satırı yazılır. Görünüş yine aura tuvalinden.
